# Qadibi AlQawi

Android application for personal health and wellness tracking, built in Kotlin using Room, Keystore, encrypted local storage, Arabic RTL support, and a developer mode.

## Features included in this initial scaffold
- Native Android app structure
- Kotlin project setup
- Room database foundation
- Security/Keystore scaffolding
- Dashboard and navigation
- Arabic/English ready resources
- Dark/light mode theme base
- Developer-mode and settings placeholders

## Open in Android Studio
1. Install Android Studio (Ladybug or newer recommended)
2. Open the repository folder
3. Let Gradle sync
4. Build/run the app on an emulator or device

## Important note
This initial repository provides the application foundation and architecture. Further modules for measurements, photo journal, symptom tracking, encrypted backups, and the full developer panel can be expanded in subsequent iterations.
